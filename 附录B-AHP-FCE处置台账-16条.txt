## 处置明细（13 原条 + 3 北辰修正 = 16 条）

### 1. 三标度法(0,1,2)比较矩阵 → 借鉴（组件）→ 落点 9.7
迁移需求：ExpertSim/AHP 采集端在准则或指标数 >7 时切换三标度预采集模式：先按 0/1/2（劣/同/优）采集比较矩阵，再数学转换回 1-9 标度；≤7 保持 1-9 直采。
理由：两两比较次数 n(n-1)/2 随准则数平方增长（n=8 时 28 次、n=10 时 45 次），三标度把每次比较的认知负荷从 9 档压到 3 档（论文指出 n>7 认知过载）。

### 2. 式(3)(4) 标度转换 → 借鉴（组件）→ 落点 9.7
公式：r_i = Σa_ij；b_ij = (r_i−r_j)/(r_max−r_min)×(k_m−1)+1
迁移需求：代码层实现转换函数 transform_scale()；k_m=9 为默认可配置参数，登记「来源=论文惯例，非标定值」（阈值声明前置铁律）。

### 3. 式(5)(6) 最优传递矩阵 P / 拟优一致性矩阵 D → 条件借鉴（协议）→ 落点 9.8
迁移需求：CR 门升级双轨：CR>0.1 → 先跑最优传递矩阵自动修正 → 重算 CR 并登记修正前后权重对比 + CR 对比轨迹；两轮仍不过 → 打回重打分。修正事件必须留痕。
防的坑：一致≠正确——一致性修正只保证传递性，专家系统性偏差被完美保留（一致的 garbage 仍是一致的）。
【北辰修正A】经修正的权重，其下游结论置信度强制降一档（修正掩盖分歧而非消除，仅留痕不改变可信度外观）。

### 4. FCE 完整管线（评语论域 + 隶属度矩阵 R + B=W·R + v=B·Vᵀ）→ 借鉴（组件）→ 落点 9.9
迁移需求：or_toolbox 增第 13 方法 fce.py：输出「等级隶属度向量 + 综合得分」双件；适用场景=多方案多维度的等级制评价输出（A vs B 裁决要「档位+得分」时用）；权重输入必须来自 AHP/ExpertSim 已过质检管线（论文「逻辑清洗」思想=上游 SARQ/收敛门），禁止裸权重进 FCE。

### 5. 加权平均型算子 → 借鉴（协议）→ 落点 9.9
迁移需求：fce.py 默认加权平均算子（保留全部指标信息）；同时强制输出短板检测列：最低两级评语累计隶属度 + 逐指标 min 隶属度。
补的论证缺口：论文 3.1 节以「威慑存在短板效应」弃用主因素突出型算子，但加权平均算子恰恰识别不了短板——短板要靠低等级累计隶属度侧面看，论文未做（L11 自相矛盾点）。

### 6. 频数/n 隶属度统计（50 专家）→ 等价映射 → 落点 9.11
迁移需求：不重建人工专家池；公式迁移用途=多路独立评分的等级投票聚合：ExpertSim 鹰/鸽/中立三视角 + 多路独立重跑输出各自等级 → 频率统计 → 隶属度向量。

### 7. V'={100,85,70,55,40,25} 线性等距赋分 → 否决 → 不落点
否决理由：等距赋分无论证（L4：差值 15 纯属设定）；保留 skill 档位语言 + Wilson 区间制，禁止照搬数值锚。

### 8. 层次建模 / 效能梯度排序 / 动态修正展望 → 已装 ×3 → 不落点
说明：§9.2 AHP 三层建模器 / gap_to_best-worst 双向择优 / ForecastRegistry + 周一监控 + 步⑫复判均已覆盖且超前于论文（论文动态修正仅停留在结束语展望）。

### 9. （双方盲区）无评分者一致性检验 → 新增（补盲）→ 落点 9.10
迁移需求：fce.py / ExpertSim 多路评分时输出 Kendall's W 或 Fleiss' κ 评分者一致性；W/κ 过低 → 结论挂「专家分歧大」标注，禁止包装成共识。
【北辰修正B】三件套（频数隶属度/W·κ/Wilson CI）启用门槛=独立评分路数 ≥10；10-30 参考级；>30 趋势级；<10 只报点估计+方向性标注（对齐样本量铁律：n=3 视角的频数统计噪声过大）。

### 10. （论文盲区）R 矩阵输入无质检 → 新增（补盲）→ 落点 6.7
迁移需求：进 R 矩阵前显式过 SARQ 校验位（证据/打分的来源、时效、口径三查）。论文 L7 缺口：50 份原始打分直接进 FCE，无质量闸。

### 11. （论文盲区）点估计无区间 → 新增（补盲）→ 落点 9.11
迁移需求：v=B·Vᵀ 为点估计 → 隶属度是比率类、n 已知 → 用 Wilson 思想给 B 各分量配 95% CI，得分报「点 + 区间」。

### 12. （论文盲区）无算子对比/无外部回测 → 新增（补盲）→ 落点 9.9/9.11
迁移需求：双算子（加权平均/主因素突出）对照输出一次；排序结果对照 backtest_log 历史案例回测——复用已有组件零开发（L9/L10 缺口）。

### 13. （边界）三标度退化输入 → 新增（边界）→ 落点 6.7
迁移需求：r_i 全相等或 r_max−r_min 过小 → 区分度不足告警，拒绝转换（转换公式在退化输入下产出无意义矩阵）。

### N1.【北辰修正A】修正置信度降档 → 落点 9.8
内容见条目 3。外部处置方案仅要求留痕，北辰加码：置信度降一档。

### N2.【北辰修正B】路数分档门槛 → 落点 9.10/9.11
内容见条目 9/11。外部处置方案未定 n_min，北辰定死：≥10 才启用统计三件套。

### N3.【北辰修正C】评分主体同源性声明 → 落点 13.7（唯一新增 P0）
LLM 多路评分场景必须在结论前声明：「独立性来源=温度/seed 扰动，评分主体同源，非独立专家池」；同源共识不得包装为独立交叉验证。声明前置铁律扩展条款。

## 生效顺序（顺序敏感，并入 v9.1 时执行）
1. 三标度转换（9.7）必须发生在采集之后、CR 门（9.8）之前；
2. 最优传递矩阵修正挂在 CR 门失败分支内，不得跳过 CR 复检；
3. FCE（9.9）属阶段三输出环节，权重未过 SARQ/收敛门不得进入；
4. 一致性系数（9.10）在多路评分聚合时计算，路数不足走 9.11 降级路径。
