# 情报收集分析评估预测多Agent系统

## 系统架构（四层架构）

基于6个关键修正 + 专业领域能力地图设计

```
┌─────────────────────────────────────────────────────────┐
│  用户交互层                                              │
│  移动端网页 · 对话工作台 · 工作流图 · BI报表 · 证据关系图    │
│  React + TypeScript + ECharts                            │
└─────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────┐
│  应用服务层                                              │
│  任务API · 工作流编排 · 身份与权限 · 任务状态持久化         │
│  Python + FastAPI + Pydantic                             │
└─────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────┐
│  Agent与检索层           │  分析与算法层                    │
│  研究执行Agent           │  统计分析（Pearson/Bootstrap）  │
│  RAG检索                 │  因果审查（Granger/DID/IV）     │
│  工具调用                │  预测模型（ARIMA/Prophet）      │
│  证据综合                │  运筹优化（LP/MIP）             │
│  LLM推理                 │  异常检测（IQR/Z-score）        │
└─────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────┐
│  数据与治理层                                            │
│  SQLite → PostgreSQL · 证据登记 · 预测登记 · 审计日志      │
│  权限治理(M14) · 承诺等级(M21) · 模型健康(M20)             │
│  确定性规则引擎，不由LLM控制                               │
└─────────────────────────────────────────────────────────┘
```

## 核心原则

1. **确定性治理层**：M21/M14/M8/M19/M20 由普通代码实现，不由LLM控制
2. **分层执行单元**：主控Agent + 研究执行Agent + 分析执行Agent（非多Agent数量）
3. **独立验证闭环**：预测登记 → 监测 → 结算 → Brier Score校准
4. **手机端适配**：手机作为开发/展示入口，重计算放云端
5. **可视化四类**：业务指标报表、证据关系图、工作流视图、预测校准视图

## 执行单元划分

| 执行单元 | 职责 | 实现方式 | 对应岗位 |
|---------|------|---------|---------|
| 主控编排层 | 任务契约、状态机、最终交付 | FastAPI + 工作流引擎 + 主控Agent | 后端工程师、架构师 |
| 研究执行单元 | 采集、证据提取、数据整理 | 研究Agent + 工具函数 + RAG | Agent工程师、数据工程师 |
| 分析执行单元 | EDA、统计检验、预测分析 | 分析Agent + 算法库 | 统计分析师、ML工程师 |
| 治理验证层 | 权限、承诺等级、预测结算、审计 | 确定性代码服务 | 安全工程师、数据治理 |
| 可视化层 | 报表、工作流图、证据关系图 | React + ECharts + D3.js | 前端工程师、BI工程师 |

## P0功能范围（33条核心需求）

**阶段1：可靠核心（P0）**
- M1 数据采集（多源检索、反向检索、一手源直读）
- M2 数据治理（清洗去重、异常值、口径检查、分层标注S/B/C）
- M3 EDA探索性分析
- M5 因果审查门（格兰杰/DID/IV/RDD适用性检查）
- M12 证据链治理（三角验证、冲突管理）
- M13 结构化报告（结论先行、声明前置）
- M14 权限治理（确定性规则，单向收紧）
- M8 预测登记与结算（不可覆盖、Brier Score）
- M21 承诺等级控制（A/B/C/D/BLOCKED规则引擎）
- M19 状态机（断点恢复、熔断）

**阶段2：P1分析插件**
- M4 特征工程（PCA、特征选择）
- M6 模型选择Agent
- M7 模型评估与验证
- M9 决策优化（AHP、多目标优化）
- M10 风险预警
- M11 知识图谱
- M16 多指标评价（MEREC、FCE）

**阶段3：P2高级功能**
- M15 指标体系构建
- M17 运筹算法库（排程、Pareto）
- M18 仿真推演（蒙特卡洛、离散事件）
- M20 模型健康监控（漂移检测）

## 技术栈

**后端**
- Python 3.10+
- FastAPI（API框架）
- Pydantic（Schema验证）
- SQLite（手机端轻量存储）
- LiteLLM（统一模型调用）
- httpx（异步HTTP）

**前端**
- React 18 + TypeScript
- ECharts（图表）
- D3.js（知识图谱可视化）
- React Flow（工作流图）

**分析算法**
- NumPy、Pandas（数据处理）
- SciPy（统计检验）
- statsmodels（时间序列）
- scikit-learn（机器学习）
- NetworkX（图分析）

**部署**
- Docker（容器化）
- 手机端：轻量API客户端 + 云端服务

## 验收标准（按领域）

| 领域 | 验收指标 |
|-----|---------|
| 数据采集 | 采集成功率≥90%、来源覆盖率、重复率<5%、更新延迟<24h |
| 数据治理 | 字段完整率≥95%、口径冲突检出率100%、错误数据处理正确率100% |
| Agent | 任务完成率≥85%、工具调用正确率≥90%、失败可追溯率100% |
| RAG与证据链 | 引用可定位率100%、引用支持结论比例≥80%、重复来源识别率100% |
| 预测 | Brier Score≤0.25、校准度偏差<5%、基线比较优势明显 |
| 运筹优化 | 约束满足率100%、不可行方案识别率100% |
| 报表与交互 | 关键操作完成率≥95%、页面响应<2s、错误恢复成功率100% |
| 系统运维 | 故障恢复时间<5min、任务丢失率0%、审计完整性100% |

## 手机端部署建议

- 手机作为开发、操作和展示入口
- 持续任务及重计算放云端服务
- 本地SQLite存储任务状态，支持断点恢复
- API客户端调用云端LLM和分析服务
- 不能假设手机上Python进程可长期驻留
