# Code Review Skill

## 检查维度

### 1. 代码质量
- PEP8规范
- 类型注解完整性
- 文档字符串
- 命名规范

### 2. 架构一致性
- 模块是否符合四层架构（L1/L2/L3/L4）
- 职责划分是否清晰
- 依赖方向是否正确（上层→下层）

### 3. 潜在BUG
- 空值/None处理
- 并发安全（锁、事务）
- 异常处理完整性
- 资源泄漏（连接未关闭）

### 4. 安全漏洞
- SQL注入风险
- 认证/授权缺失
- 敏感信息硬编码
- 输入验证不足

### 5. 性能问题
- N+1查询
- 不必要的重复计算
- 大对象内存占用

```markdown
| 文件:行 | 问题 | 修复建议 |
|---------|------|---------|
| ... | ... | ... |

## 警告 (建议修复)
| 文件:行 | 问题 | 建议 |
|---------|------|------|
| ... | ... | ... |

## 改进建议
| 文件 | 建议 | 优先级 |
|------|------|--------|
| ... | ... | ... |
```

## 使用方式
1. 运行审查：`python3 skills/code-review/run.py`
2. 查看报告：`cat docs/reviews/code_review_*.md`
3. 确认修复：修改代码后重新审查
