# 认知偏差治理层（Cognitive Bias Guard）

来源：《认知偏差大全》信息图（主人 2026-10-28 提供）。
定位：**只提示、追问、分级，不判定对错、不自动改写**——偏差是系统性倾向，是否成立要由证据和人来裁决。

## 一、图面口径（已核对，不照抄）

图面 10 类共 40 个条目位，实际**唯一偏差 35 条**：

| 去重类型 | 条目 | 处理 |
|---|---|---|
| 跨类重复（4 条） | 锚定效应（记忆/其他）、从众效应（情绪/社会）、损失厌恶（情绪/决策）、框架效应（决策/其他） | 各保留一条，另一处记为 placement |
| 同义合并（1 组） | 证实偏差 ≡ 确认偏误 | 证实偏差记为 alias |
| 错别字/OCR | "社尴偏差"、"过度概误" | 按语义归一为"社会偏差""过度概括" |

10 类：记忆 / 逻辑 / 情绪 / 自我相关 / 社会 / 决策 / 行为 / 经济 / 信息 / 其他常见。

## 二、代码结构

```
src/infra/bias/
├── taxonomy.py     35 条唯一偏差的单一事实源（定义/别名/文本指标/自问/对策/作用域/严重度）
├── detector.py     BiasDetector：文本层 + 证据结构层 + 提问前提层，确定性、不调 LLM
├── wiring.py       attach_bias_tools(agent) + prompt_block(scope)
└── __init__.py
```

### 三层检测

| 层 | 入口 | 判什么 |
|---|---|---|
| 文本层 | `audit_text(text, scope)` | 按句切分 + 强/弱指标双档（强指标单独命中；弱指标需 ≥2 个才报），压误报 |
| 证据结构层 | `audit_evidence(claims, evidence)` | 幸存者（零反证/零失败样本）、确认偏误（反证 <20%）、信息茧房（域名 ≤1）、缺基率（无分母标记） |
| 提问前提层 | `audit_question(question)` | 预设前提、假两难、绝对化、无源数字、幸存者框架、诉诸权威、因果断言、缺基率、口径缺失；输出风险分级 + 澄清问法 |

`full_audit()` 把三层合成一次调用，按 `block / downgrade / review` 分级返回。

- `tests_bias` 55 项：知识库完整性、35 条逐条可检出、中性文本零误报、弱指标不误触、提问前提 4 类、证据结构正反例、m13 并入与检出、reflection 集成、两 Agent 挂载。
- 全量 `tests + tests_m23 + tests_bias` = **131 passed**，无回归。

## 五、边界（必须说清）

1. **关键词/结构判定 ≠ 语义判定**：只覆盖"能写成规则"的偏差；讽刺、隐喻、反讽式引用会漏。高代价场景仍需人工复核。
2. **命中不是错**：比如"所有"在定义句里合法。输出一律是"追问 + 复核建议"，不阻断交付。
3. **提问审计只审"表述"，不审"事实"**：它能指出"你假设了 A 成立"，不能替你验证 A。
4. **与 M24 多模型质检的分工**：本层是**确定性、零成本、可离线**的第一道筛；跨厂商多模型交叉评审（M24）是第二道，二者互补，不互相替代。
5. 阈值（如反证占比 20%、域名 ≤1）为**先验值**，需按实际语料回测后再调。
