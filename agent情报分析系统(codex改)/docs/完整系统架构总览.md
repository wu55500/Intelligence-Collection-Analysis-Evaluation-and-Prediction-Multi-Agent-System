## 6个关键修正的落地实现

### 修正1：M21三层分离
- **子模块层**：各模块报告数据质量、冲突、失败 → 不自行提级
- **规则引擎层**：`CommitmentEngine.evaluate()` → 普通代码执行规则
- **交付层**：`ReportGenerator` 根据裁决组织报告 → 不能擅自提级

### 修正2：执行单元非Agent数量
- 研究执行单元：`ResearchAgent` + 工具函数
- 分析执行单元：`AnalysisAgent` + 算法库
- 治理层：确定性代码服务（无LLM）
- 总共2个Agent + 4个确定性服务

### 修正3：关键模块不是普通Agent
- M8→`ForecastService`（数据库服务+规则引擎）
- M14→`PermissionService`（确定性策略执行器）
- M19→`WorkflowOrchestrator`（状态机+持久化）
- M21→`CommitmentEngine`（规则引擎+审计记录）

### 修正4：完整任务协议
- `TaskContract`包含：task_id, input_hash, method_version, status, evidence_refs, error_code, retryable, output_hash, commitment_level, permission_level
- 幂等性：输入哈希防重复
- 持久化：SQLite WAL模式
- 审计：所有操作记`AuditLog`

### 修正5：预测验证闭环
- `register_forecast()` 只追加，不覆盖
- 保存`evidence_snapshot`防未来证据污染
- `settle_forecast()` 独立结算
- `calculate_brier_score()` 与基线比较
- 100条结算后系统性复盘

### 修正6：分层扩展
- P0先验证闭环（已实现代码骨架）
- P1按瓶颈拆分
- P2按价值扩展
