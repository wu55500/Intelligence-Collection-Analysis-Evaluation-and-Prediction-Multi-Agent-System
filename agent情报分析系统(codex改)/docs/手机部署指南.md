# 手机端部署指南（vivo Y200i）

## 你的手机配置分析

**vivo Y200i 关键参数**：
- 存储：512GB（已用203GB，剩余308GB）✅ 充足
- 网络：5G ✅ 高速连接
- RAM：约6-8GB（中端机）
- 芯片：Snapdragon中端（不适合本地跑大模型）

**结论**：手机**不适合**本地跑完整的Python+LLM系统，但非常适合做**开发入口+控制面板**。

## 推荐架构：手机控制 + 云端运行

└─────────────           └─────────────────────┘

## 你需要安装/购买的东西

### 1. 腾讯云轻量应用服务器（必须）

你已经注册了腾讯云，这是最关键的一步。

**购买建议**：
- **最低配置**：2核4GB内存，40GB SSD
- **系统**：Ubuntu 22.04 LTS
- **价格**：约50-80元/月（新用户有优惠）
- **地域**：选离你近的（华南/华东）

**购买后操作**：
1. 登录腾讯云控制台
2. 点击"轻量应用服务器"
3. 选择"新建"
4. 镜像选"Ubuntu 22.04"
5. 套餐选"2核4GB"
6. 完成后记录**公网IP**和**root密码**

### 2. 手机端APP（全部免费）

必须安装：
```
1. Termux（终端模拟器）
   - 从F-Droid下载：https://f-droid.org/packages/com.termux/
   - 不要从Play Store下载（版本过旧）

2. Termux:API（扩展功能）
   - 从F-Droid一起下载

3. Acode（代码编辑器）
   - Play Store搜索"Acode editor"
   - 支持语法高亮、Git集成

4. JuiceSSH（SSH客户端）
   - Play Store搜索"JuiceSSH"
   - 用于连接云服务器

5. Termux:Boot（开机自启，可选）
   - 保持后台任务运行
```

可选安装：
```
6. Git客户端（如果不用Termux的git）
7. 腾讯云APP（管理服务器）
8. 钉钉/企业微信（接收告警通知）
```

### 3. 云端服务器配置（买完服务器后执行）

通过JuiceSSH连接到服务器，然后执行：

```bash
# 1. 系统更新
sudo apt update && sudo upgrade -y

# 2. 安装Python和依赖
sudo apt install -y python3.11 python3-pip python3-venv git

# 3. 创建项目目录
mkdir -p ~/intel-system && cd ~/intel-system

# 4. 克隆项目（从GitHub或本地上传）
git init
# 上传代码到服务器...

# 5. 创建虚拟环境
python3.11 -m venv venv
source venv/bin/activate

# 6. 安装依赖
pip install -r requirements.txt

# 7. 启动服务
cd src/api
python -m uvicorn main:app --host 0.0.0.0 --port 8000
```

### 4. 手机上的工作流

**日常开发流程**：

```
早上：
1. 打开JuiceSSH → 连接云服务器
2. 检查系统状态：curl http://localhost:8000/health
3. 查看待处理任务

工作中：
4. 用Acode编辑代码（本地或服务器）
5. 用Termux执行测试：python -m pytest
6. 提交Git：git add && git commit && git push

晚上：
7. 查看审计日志
8. 检查预测结算结果
9. 接收告警通知
```

### 5. 代码同步方案

**方案A：Git（推荐）**
```bash
# 手机Termux
git clone <你的仓库>
cd intel-system
# 编辑后用Acode或vim
git add . && git commit -m "update"
git push
```

**方案B：SCP/SFTP**
```bash
# 从手机上传到服务器
scp -r ./intel-system root@<服务器IP>:~/

# 从服务器下载到手机
scp -r root@<服务器IP>:~/intel-system ./
```

**方案C：云同步**
- 用腾讯云COS或OSS同步代码
- 适合大文件（数据、模型）

### 9. 常见问题

**Q: 手机后台杀进程怎么办？**
A: 不要在手机本地跑服务，全部放云端。手机只做客户端。

**Q: 5G流量够用吗？**
A: 代码同步和API调用流量很小，主要流量是下载数据。建议连WiFi时同步大文件。

**Q: 服务器挂了怎么办？**
A: 腾讯云有自动快照，每天自动备份。数据不会丢。

**Q: 能离线工作吗？**
A: 代码编辑可以离线，但LLM调用和云端服务需要网络。

**Q: 需要买域名吗？**
A: 初期不需要，用IP访问即可。后期如果要对外服务再买。
