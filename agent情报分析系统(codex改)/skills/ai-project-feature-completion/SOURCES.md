# Source and scope notes

This skill synthesizes general software engineering practice with the project-planning ideas supplied by the user, including:

- work backward from project capabilities and job requirements;
- decompose requirements into functions/modules and map those to techniques, technical stacks and engineering disciplines;
- study open-source repositories and comparable projects critically;
- account for hardware, GPU/VRAM, memory, OS, containers, network/API availability, cost and operational feasibility;
- use an iterative research → requirements synthesis → scoped implementation → independent review → verification loop;
- assess architecture, code standards, maintainability, test cases and CI/CD for interview/project review;
- score projects with explicit reasons and evidence, rather than judging only visual polish or whether AI helped generate code.

The scorecard's 60/100 pass-floor language is a practical interview-practice convention requested for this rubric, not a validated hiring cutoff. The general skill is not a certification and does not guarantee recruitment outcomes. Check official tool, framework, security and deployment documentation for stack-specific requirements when applying the skill to a real repository.
